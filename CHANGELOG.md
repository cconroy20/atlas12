# ATLAS12 + SYNTHE — Modernization Ledger

The complete record of the translation from Robert L. Kurucz's Fortran 77
originals: every structural, numerical/physical, and hygiene change, with
design rationale, validation numbers, and post-mortems.  A compact
current-state summary lives in the README ("Translation from Fortran 77"
section); open items are tracked in [atlas_to_do.md](atlas_to_do.md).

Entries within each section are in rough chronological order.  Where a
later entry revisits an earlier one (e.g. a flag default changed after
further hardening), the later entry stands.

## Structural

- Free-format Fortran 90 source; explicit typing throughout; `-r8` flag removed
- 58 COMMON blocks consolidated into two modules (`mod_parameters`, `mod_atlas_data`)
- 829 EQUIVALENCE statements eliminated
- Full GOTO elimination pass: 38 → 0 active GOTOs across all four files, including a refactor of the `JOSH` radiative transfer solver
- Command-line argument parsing replaces card-based input for ATLAS12 driver options
- The `mklinelist` line-list preprocessor (formerly the standalone `synbeg | rgfall | rpredict | rmolecasc | rh2ofast` shell pipeline) absorbed into the SYNTHE executable as `mod_mklinelist`, dispatching from a single plain-text `lines.list` manifest
- SYNTHE three-program pipeline (XNFPELSYN, SYNTHE, SPECTRV) merged into a single executable with all inter-stage data flow in memory; intermediate binary scratch files (`fort.9`, `fort.10`, `fort.13`, `fort.14`, `fort.15`, `fort.93`, `spectrv.input`) eliminated
- ASCII spectrum output written directly by SYNTHE (`.spec`), eliminating the standalone `syntoascanga` post-processing step

## Numerical and physical

- Atmosphere state arrays (T, P, ρ, χ, populations) promoted from REAL(4) to REAL(8)
- Physical constants consolidated into `mod_constants` with CODATA 2018 values, replacing ~130 scattered literals
- Atomic partition functions replaced with the Barklem & Collet (2016) tabulated U(T) calculated by direct NIST level summation, covering Z = 1..92 in ionization stages I–III; the legacy Kurucz hand-selected few-term sums used by `PFGROUND` (the low-T floor in `PFSAHA`) and the generic `NNN` interpolation table are retained as an internal safety net but are no longer the production data source.  Iron-group partition functions (Z = 20..28) still flow through `PFIRON` for its pressure-lowering correction, but the unperturbed POTLOW = 0 baseline is now anchored to B&C
- Metal continuum bound-free opacity overhauled: a new `CONT_METAL_OPACITY_TOPBASE` dispatcher replaces the legacy collection of analytic Seaton/Peach fits (Li1OP, C1OP, MG1OP, AL1OP, SI1OP, FE1OP, …).  `MBF_TOPBASE` supplies 30 species (neutrals and first ions of Li, Be, B, C, N, O, F, Ne, Na, Mg, Al, Si, S, Ar, Ca) from R-matrix Opacity Project cross sections processed by Allende Prieto, Hubeny & Lambert (2003, ApJS 147, 363) into resonance-averaged 3%-log-spaced grids; `MBF_HIGH_ION` supplies higher ionization stages and Coulomb free-free from a filtered subset of `hotop.dat`; `FELO_OPACITY` supplies Fe I and Fe II from Iron Project / Opacity Project R-matrix calculations (Bautista 1997 for Fe I, Nahar & Pradhan 1994 for Fe II, sourced from the TLUSTY model atoms).  Toggleable via `USE_TOPBASE_MBF`; the legacy path is preserved for reference.  Known limitation: TOPbase identifies levels by LS term without resolving J, so per-species opacity carries a U_TB/U_BC factor of a few percent for most species (≲13% for the worst case, Ar II)
- Solar reference abundance pattern is now selectable at the command line (`solar=name`).  The compiled-in default remains Anders & Grevesse (1989), defined once in `mod_atlas_data` and shared by ATLAS12 and SYNTHE; `solar=` replaces the abundance table carried by the input model file while preserving its relative [M/H] offsets, and `zscale=`/`abund=`/`heabnd=` overrides apply on top.  Additional named scales are stored as log-ε tables and converted internally (`LOGEPS_TO_ABUND`); registered scales: `ag89` (Anders & Grevesse 1989), `agss09` (Asplund et al. 2009), `berg25` (Bergemann, Lodders & Palme 2025, with A(He) = 10.922 from the published compilation).  (An earlier changelog entry here claimed the default had been switched to Asplund et al. 2009 — that change was never made; the code default has always been AG89.)
- Hydrogen line profiles now use the Stehlé & Hutcheon (1999) MMM tabulated Stark broadening profiles via `hydrogen_line_profile`, replacing the Kurucz–Peterson (1982) analytic approximation; the K–P path is retained as a fallback for atmospheric layers exceeding the Inglis–Teller density limit, controlled by the `USE_KP_HYDROGEN` flag
- Voigt function evaluated via Weideman (1994) N=32 rational approximation of w(z) plus Humlíček (1982) R₁,₂ asymptotic, replacing the Kurucz three-regime table approximation that had ~4% error at the a = 0.2 regime boundary.  Accuracy is now ~10⁻⁵ relative across the full (a, v) plane with no regime boundaries
- The H⁻ bound-free photodetachment cross section in `HMINOP` replaced: the Mathisen (1984) / Wishart (1979) / Broad & Reinhardt (1976) 85-point table is superseded by McLaughlin, Stancil, Sadeghpour & Forrey (2017, J. Phys. B 50, 114001), resampled onto 116 points.  The old table ran ~0.1–1.4% high through the optical (growing toward 8000–9000 Å); the swap removes a ~1% optical continuum offset against Korg, which adopts the same source (the free-free table — Bell & Berrington 1987 — was already common to both codes, isolating the difference to the bound-free data).  The resampling reproduces the smooth optical/IR continuum to <0.05% under the code's own MAP1 interpolator; the narrow far-UV Feshbach resonance (113.4 nm, ~0.02 nm wide) is deliberately represented by its broad envelope only — a table fine enough to resolve it would ring under MAP1, and it is negligible for the continuum.  The non-LTE H⁻ polynomial in `STATEQ` is untouched (the non-LTE branch is unused in production).  Below the free-free table's 1400 K edge, `HMINOP` extrapolates linearly in θ = 5040/T — verified against the table's own curvature to ≤2% at 1200 K and ≤7% at 1000 K; a literature check found no replacement source at stellar temperatures (the Schleicher et al. 2008 low-T fit runs ~40% high)
- H₂ partition function read from an external data file rather than hardcoded
- The `JOSH` scattering solution is now a direct dense solve of the 51-point integral-operator system (I − diag(α)·Λ_J)·S = (1−α)·S̄ via `SOLVIT`, replacing the Gauss–Seidel Λ-iteration.  The iteration stalled against its 50-sweep cap once the scattering albedo α exceeded ~0.99 across the grid — 0.3% error in S at α = 0.99, 10% at α = 0.999, accepted after a warning — and its 10⁻⁵ early-exit tolerance quantized the response of every scattering solve, leaving discontinuous noise in H_ν at the tolerance level.  The direct solve is exact at comparable cost (one 51×51 LU per frequency) and reproduces the iteration to its own tolerance wherever the iteration converged (`workdir/pfverify/josh_verify.py`, Test D)
- Optional Steffen (1990) monotone-cubic quadrature for `INTEG` (developer flag `IQUAD = 1` in `mod_atlas_data`), the routine that builds τ_Ross, the per-frequency τ_ν, P_rad, and the height scale.  The legacy blended-parabola quadrature (`PARCOE`) integrates a 5-decade exponential on real model grids with 1.3% (solar) to 11% (2800 K) maximum error — only ~2× better than a trapezoid — while the Steffen cubic is 3–6× more accurate and its monotone interpolant keeps τ scales monotone with no overshoot (`workdir/pfverify/josh_verify.py`, Test C).  The quadrature error is concentrated in the deepest layers, so switching moves converged structures mainly at the grid bottom: ≤1.5 K in cool/warm stars (convection pins the deep adiabat) but 0.1–0.5% of T in hot-star radiative envelopes (47–105 K at 8000–40000 K), with equal convergence quality and negligible emergent-flux change.  The default remains the legacy quadrature
- Partition-function tables (H₂ and Barklem & Collet) evaluated with natural cubic splines instead of (log-)linear interpolation.  The interpolation kinks at table nodes, sampled by the EOS finite-difference stencil, imprinted spurious structure on ∇_ad that F_conv ∝ (∇−∇_ad)^{3/2} amplified into large local flux errors in cool-dwarf deep convection zones.  Node values, boundary behavior, and hot-star fallbacks are unchanged (verified by the `workdir/pfverify/` battery); converged structures shift by ≲0.5 K
- Molecular equilibrium network extended and repaired.  The species list (`molecules.dat`) gains ten diatomics — CrO, CrS, TiN, TiS, TiH among existing network elements, then ScO, YO, ZrO, LaO, MnH with Sc, Mn (ion stages I–V) and Y, Zr, La (I–III, the generic partition-function path's limit) as new network elements — refit from Barklem & Collet (2016) Table 7 equilibrium constants in the same physical-form basis as the existing "BC16 fit" rows via the new `tools/fit_molecule_keq.py`, kept in-repo so the fit provenance survives with the data (its `--validate` mode regenerates all 41 pre-existing neutral-diatomic BC16 rows exactly).  Li, Be, and B — previously in the network only as neutrals bound in LiH/BeH/BH, with no ionized sink in element conservation — gain ionization stages I–III.  The Y I and Zr I ionization potentials in `ionpots.dat` are corrected against BC16 Table 4 / NIST (both were ~0.2 eV high, a ~2× overestimate of the neutral fractions at 3500 K), and the `READMOL` species-code decoder now peels digit pairs in integer arithmetic — the old real-valued rounding misread any trailing pair ≥ 50, first triggered by La (LaO = 857.00 decoded as 9, −43).  The Ti/Cr additions are EOS completeness (solar flux bit-identical; ≲0.5% broadband shifts at 2500–3500 K, where TiH depletes deep-layer TiO by ~2%), but the s-process oxides change cool-star chemistry qualitatively: ZrO, LaO, and YO lock ≳99.9% of their elements in the 2500 K photosphere (92–99% at 3500 K), collapsing neutral Zr I / Y I / La I resonance lines — previously computed with the full element atomic — by up to 10⁴ in the blue/UV; and Mn, 94% ionized at solar conditions, joins the charge balance, correcting a ~0.1% electron-density deficit.  That last mechanism generalizes — under molecular equilibrium (`IFMOL=1`, the production path) the charge-conservation equation sums network species only, so elements absent from `molecules.dat` contribute nothing to n_e (a Kurucz-era design gap: the deck's atom list was "elements that form molecules", and `NELECT`, which does sum Z = 1–30, is reachable only with molecules off).  Co, Ni, Cu, and Zn therefore enter as pure atom/ion rows (Co/Ni I–V via `PFIRON`, Cu/Zn I–III via the generic path; Co I's ionization potential corrected 63400 → 63565 cm⁻¹ on entry), recovering a Ni-dominated +0.5–0.7% n_e through the solar line-forming layers.  The solar photosphere responds by cooling 1–3 K around τ ≈ 1 (the H⁻ opacity increment), moving blue/UV flux by ~0.1% typically and 1%+ in the strongest-blanketed 1300–6600 Å line cores; cool dwarfs are nearly untouched (Ni stays neutral at 2500–3500 K until the deep layers).  Phosphorus then enters (P I–VI; PH, PN, PO, PS, P₂, CP from BC16 — at 2500 K it partitions ~49% atomic / 24% PH / 19% PO) together with the metal halides (LiF, NaF, MgF, AlF, KF, CaF, LiCl, MgCl, AlCl, NaCl, KCl, CaCl): fluorine's secondary reservoir is AlF at ~14% (HF 86%), chlorine stays 99% HCl, and alkali-halide sequestration of Na/K proves negligible down to 2500 K, so solar and cool-dwarf structures are essentially unchanged (max |dT| ≤ 0.05 K).  A final completeness pass adds KH, NiH, CoH, CuH, ZnH, ScS, YS, LaS, NaO, KO, SiF, SiCl, SF, and the Be/B families (BeO, BeF; BO, BF, BN, BS): boron turns out to be ~99.9% BO at 2500 K — its 2090 Å resonance doublet was previously computed fully atomic — while every other budget shifts by <1% (KH 0.3% of K, NiH 0.9% of Ni) and structures are unchanged.  The polyatomic legacy rows were then audited against NIST-JANAF (via the kp compilations shipped with GGchem, Woitke et al. 2018): 10 of the 12 with no ExoMol coverage agree to ≤0.09 dex — Kurucz's polyatomics trace to the same JANAF-era thermochemistry — while the two outliers got deliberate D0-consistent refits (MgOH: JANAF Kf shape with the Koput 2023 D0 = 7.581 eV, a real 0.4 eV Mg–OH bond conflict with JANAF's 7.981; HO₂: Stock/Kitzmann shape with the ATcT D0 = 7.198 eV, replacing a never-updated 7.108).  Five JANAF-route polyatomics were added — TiO₂, VO₂, AlOH, Al₂O, AlO₂H — with the largest spectroscopic consequence of the whole revision: at Teff = 2500 K, TiO₂ holds ~23% of Ti in the upper photosphere (TiO drops ~19%) and aluminium goes majority-molecular (AlOH 53%, Al₂O 36%), moving the TiO-banded optical by a median ~12% (5000–7000 Å) with a 2.3 K structure response, while the 1–2.5 μm flux carrier and all warmer models are essentially unchanged (solar bit-identical) — late-M TiO bands were systematically too strong before — gas-phase TiO₂ has been in the standard cool-star equilibria since Tsuji (1973) and at modern JANAF strength in Sharp & Huebner (1990), the declared polyatomic source of the PHOENIX EOS.  The ExoMol-route additions followed: KOH, LiOH, HBO, SiH₂ assembled from ExoMol partition functions with independently sourced dissociation energies (JANAF chains for the hydroxides; Berkowitz & Ruscic 1987 for SiH₂, whose Stock/Kitzmann entry still carries the stale pre-1987 silylene enthalpy; JANAF + the ATcT boron atom for HBO), and PH₃ as a Stock/Kitzmann-shape fit with the D0 swapped to the JANAF/CCCBDB value (the PH₃ table shipped in the GGchem JANAF folder is corrupt, and ExoMol's PH₃ partition function stops at 400 K).  At 2500 K the boron budget flips — HBO holds 94–99.5% of B, displacing BO — and PH₃ becomes the leading phosphorus hydride (PH₃/PH ≈ 3.5–7); potassium and lithium hydroxides stay trace above the brown-dwarf regime, and solar models are again bit-identical.  Finally, the molecular-ion rows were repaired: the April refit had fit the 8 BC16 ion rows in BC16's dissociation convention (atom + ion⁺) rather than the electron convention NMOLEC implements (K = n(M⁺)n_e/Πn(atoms)), underproducing molecular ions by 4–13 dex — with no observable consequence, since H₂⁺ opacity is computed from n(H)·n(H⁺) directly — and all 8 are refit with the Saha factor restored (now 0.0–0.6 dex from Kurucz's originals, which had the convention right); H₃⁺ is upgraded from the legacy polynomial (itself ~4.5 dex low) to an ExoMol MiZATeP assembly with a spectroscopic E1 = −4.771 eV, and `fit_molecule_keq.py --validate` now covers every diatomic in the file: 96/96 exact.  The network now carries 297 rows, 33 equilibrium equations (`maxeq` raised to 50).  The complete April 2026 fit pipeline now lives in `tools/` (`comp_pf.py`, `build_molecules_physical_dat.py`, `kurucz_molec.py`, and the six data modules that had been lost after that refit, reconstructed and validated by reproducing the April `molecules.dat` to 188/190 rows at printed precision — which pinned the ExoMol nuclear-spin convention and recovered the full-precision assembly D₀ values).  The fit atlas `comp_pf.pdf` is regenerated by it in the original convention — Kurucz original/updated polynomials against BC16 (diatomics) and ExoMol-assembled (polyatomics) references with the physical-form fits and residuals — including one page for every species added in July 2026 (diatomics against BC16; new polyatomics against NIST-JANAF/Stock-Kitzmann) and JANAF reference overlays on the legacy self-fit pages; the untouched April original is preserved as `comp_pf_apr2026.pdf`
- Equilibrium-condensation groundwork (data layer only; the Cond-limit solver — condensate formation depleting gas-phase abundances, no grain opacity — lands in a later change).  `data/condensates.dat` files 21 solids active above ~1000 K at photospheric pressures (corundum, perovskite, the Ti oxides TiO₂/Ti₂O₃/Ti₃O₅/Ti₄O₇, baddeleyite ZrO₂, the Ca–Al/Ca–Mg silicates gehlenite, anorthite, spinel, akermanite, diopside, wollastonite, plus forsterite, enstatite, quartz, amorphous SiO, metallic Fe and Ni, and VO/V₂O₃) as ln K(T) fits in one canonical form — ln S = Σᵢ νᵢ ln(nᵢkT) + c₀/T + c₁ ln T + c₂ + c₃T + c₄T² — referenced to free neutral atoms or, for the vapor-pressure-derived entries, to a gas-phase species carried in `molecules.dat` (TiO₂, SiO₂, SiO, VO), so the equilibrium solver can evaluate supersaturation directly from its own converged densities, thermodynamically consistent with the network's own equilibrium constants.  Thermochemistry comes from the GGchem condensate compilation (Woitke et al. 2018: NIST-JANAF, SUPCRTBL, and Sharp & Huebner 1990 fits): `tools/dustchem_loader.py` parses and evaluates every DustChem entry in GGchem's conventions — validated exact (<10⁻⁴ dex) against GGchem's computed supersaturations over 1000–2600 K for all four fit forms — and `tools/fit_condensates.py` selects sources (modern Stock-form fits where available; SUPCRTBL for anorthite, whose Sharp & Huebner entry is the known ~100 kJ/mol outlier, and for ZrO₂, where the network carries no gas-phase ZrO₂ — a deliberate 0.12 dex source difference against GGchem's vapor-pressure default), refits over 700–2600 K (21/21 round-trip below 0.02 dex; rerun `--validate` after any edit), and renders the per-species source/refit atlas `comp_cond.pdf`.  Reference equilibrium-condensation sweeps for the coming validation stages (GGchem eqcond, 2600→1000 K at log P[bar] = −6…−1, solar abundances) fix the appearance sequence at photospheric conditions: ZrO₂ at 1590–1940 K, corundum 1530–1870 K, perovskite — the TiO sink — 1440–1810 K, and gas-phase Ti already 0.1 dex depleted at 1430–1810 K, i.e. at the surface temperatures of current grid-floor models; vanadium condenses as VO(s)/V₂O₃(s) in the same window, motivating its inclusion.  Two latent out-of-bounds reads in GGchem itself (elements carrying no ion species, exposed by Zr) were patched in the local clone.
- The Cond-limit solver itself (developer flag `USE_CONDENSATION` in `mod_atlas_data`, default off — no grain opacity): condensates from `data/condensates.dat` deplete the gas-phase element abundances inside `NMOLEC`'s equilibrium solve, so molecular populations, opacities, and the electron density respond self-consistently to condensate formation.  The proven legacy gas-phase Newton solve is untouched; condensation is an outer quasi-Newton iteration on the condensed fractions F_j (formula units per total nucleus): effective abundances XAB_eff = XAB_tot − Σ ν_j F_j feed each gas solve, and F steps on the small active-set system M_jl = Σ_e ν_je ν_le/ε_gas(e) ≈ −∂ln S_j/∂F_l, requiring no nested chemistry evaluations.  (A first attempt that augmented the legacy Newton directly with ln S rows and condensate columns failed — the solver's tuned damping goes chaotic against log-space saturation rows — and each shortcut taken subsequently re-derived a piece of GGchem's active-set machinery, which the final design adopts wholesale.)  Active-set management follows GGchem's `equil_cond`: potential-ordered activation (simple, abundant condensates first; repeat offenders penalized; ln S > 10⁻³ entry hysteresis), deactivation of only the most-negative candidate under thermodynamic competition, shared-element budget normalization bounding total depletion at (1 − 10⁻¹²) of each element — the per-phase candidate cap must sit at the same ceiling: left at (1 − 10⁻⁶) it deadlocked ZrO₂ at 2500 K, whose equilibrium gas remnant is ~5×10⁻⁷ of total Zr, freezing ln S at +0.59 and cascading through outer-cap evictions, depletion gaps between condensing neighbors, and the resulting opacity discontinuity into a clamp-saturated temperature-correction runaway that ended in NaN — multiplicative remnant steps for deeply supersaturated phases (a linear step cannot take a 4-dex remnant move), progressive step damping past outer iteration 40 (which also settles a genuine gehlenite/anorthite two-phase oscillation at the phase-richest 2500 K layers), worst-phase eviction at the outer iteration cap, pure-gas fallback as a last resort, and per-layer warm starts seeded from the neighboring cooler layer.  Hardening from the 2500 K battery: absolute 10⁻²⁰ remnant floors (a relative-only floor underflowed the legacy solver's own contract for Zr), NaN gates at the gas-Newton exit (NaN fails every `.GT.` test, so a poisoned state previously "converged" silently) with re-seeded recovery, and exhaustion-as-convergence for phases whose limiting element sits at its floor.  Validation is two-stage.  Point-matched chemistry (`tools/validate_condensation.py`, consuming the per-layer "COND:"/"CONDEPS:" run-log diagnostics): GGchem eqcond rerun at each condensing layer's exact (T, P) with the model's own abundances reproduces the phase assemblage exactly (except ZrO₂ held ~50 K hotter — the documented SUPCRTBL source swap plus GGchem's missing Zr⁺) and the per-element gas abundances to ≤0.03 dex for Ti/Al/Si; Ca's −0.10 dex traces to a +0.034 dex free-atomic-oxygen offset between the gas networks (BC16 vs GGchem kp for CO/H₂O/SiO) amplified ×7 by gehlenite's stoichiometry — ordinary cross-code thermochemistry scatter (GGchem's own cross-code agreement is ~0.05 dex) — and Zr's −1 dex is the two Zr systematics amplified exponentially in a >99.99%-condensed remnant.  Structure battery: solar and 3500 K flag-ON runs are bit-identical to flag-OFF (nothing condenses); the 2800 K dwarf (30 iterations) cools −25…−41 K over the condensing zone log τ ≈ −5.1…−4.5 with +25 K just below (max |ΔT| = 41 K — same class and sign as the MSG ~25 K upper-layer effect at the 2500 K grid floor, the published measure of what condensation is worth there); the 2800 K giant condenses only trace ZrO₂ at its low pressures (≤0.6 K response); and the 2500 K dwarf — the failure that drove the hardening — completes 30 iterations at the flag-OFF pace (~70 s/iter) with condensing-zone flux closure at 0.16% and an A/B of −12…−24 K cooling over log τ ≈ −3.5…−2.2 with +3…+7 K warming below (the 1500 K temperature floor pins everything above log τ ≈ −3.5 in both runs, so the true surface response is larger); the handful of one-shot outer-cap evictions that remain there self-correct on the following call, and the τ ≈ 1 transition's pre-existing few-percent residual is modestly perturbed (12.0% vs 9.3% peak), unrelated to the condensing layers.  Perturbed EOS-derivative re-entries reuse the converged assemblage, and a per-layer outer-iteration trace (`COND_DBGJ`) is available for solver forensics.
- Iron-group partition functions extended below the PFIRON grid edge.  The Kurucz iron-group table (Ca through Ni, all ion stages) bottoms out at log T = 3.32 (2089 K); below it the clamped interpolation froze U at the lowest node, and an initialization gap (the B&C rescaling ratio unpopulated for node 1) faded the Barklem & Collet anchoring back to pure Kurucz exactly where it mattered most — a regime every temperature-floor-pinned layer of 2500 K models occupies.  Ions I–III now evaluate the B&C U(T) directly below 1900 K (tabulated to arbitrarily low temperature), keep the legacy path at and above 2100 K, and blend with a C¹ smoothstep between so the finite-difference EOS derivatives that sample U see no kink; the pressure-lowering correction is dropped in the pure-B&C regime (POTLOW is negligible at these temperatures), and ion stages ≥ 4 keep the frozen clamp (unpopulated below 2000 K).  Verified: solar and 3500 K models bit-identical (the fix is inert above the blend window); the 2500 K dwarf moves ≤ 4 K with peak flux error improving 9.3% → 7.8%.
- The TCORR temperature floor lowered from 1500 K to 1200 K (now the developer variable `TFLOOR_ATM` in `mod_atlas_data`).  The 1500 K clamp pinned the top third of the depth grid at the coolest Teff — an isothermal plateau rather than a solution of the flux equations — and an audit of every temperature-indexed data path showed it protecting almost nothing: the edges above it (PFIRON at 2089 K, now extended; the CH/OH photodissociation tables at 2000 K, log-linearly extrapolated) were already crossed by every pinned layer; the H− free-free table edge at 1400 K (θ = 3.6) is followed by a linear θ-extrapolation verified good to ≤2% at 1200 K against the table's own curvature (and further diluted by the vanishing electron density there — a literature check found no replacement source at stellar temperatures, the Schleicher et al. 2008 low-T fit running ~40% high); and everything else — B&C atomic partition functions, the H₂ partition function, H₂/He CIA, condensate fits, the molecular-equilibrium fit forms, Stehlé profiles (graceful fallback), TOPbase metal continua (no temperature tables at all) — remains in validity.  The floor's true lower bound turned out to be the SOLVER, not the data: pushed to 1000 K, the 2500 K dwarf walked its surface down normally for 18 iterations until, at T(1) ≈ 1050 K, the molecular-equilibrium Newton diverged (the equilibrium n_e of ~10² cm⁻³ against 10¹²⁺ atom densities and K_eq ~ e¹⁰⁰⁺ spans ~90 orders of magnitude — the charge row is lost in double precision, the same regime GGchem handles in quadruple precision) and the NaN spread to every layer through the depth warm-start.  1200 K keeps a safe margin above that wall; sub-1200 K photosphere tops require a low-temperature gas-solve hardening filed as future work.  Structure changes (production flag-OFF path, all converged with zero warnings): the 2800 K giant's surface relaxes 1500 → 1283 K (−217 K; the floor no longer binds anywhere in the model), the 2800 K dwarf's 1500 → 1385 K (−115 K, floor unbound, peak flux error 0.87% vs 1.08%), and the 2500 K dwarf's surface drops the full 300 K to the new floor, which now pins only the top ten layers (log τ ≲ −5.8, was ≲ −3.5) — releasing the plateau also lets the whole model close flux far better (peak error 2.25% vs 7.8%).  Solar and 3500 K models are bit-identical (their structures never approach the floor).
- Equilibrium condensation is now ON by default (`USE_CONDENSATION = .TRUE.`), after the Cond-limit solver was hardened for the 1200–1400 K photosphere tops the lowered temperature floor exposes — a regime with a far richer phase field than the floor-1500 models the solver was built against.  Four independent failure modes were found and fixed there.  (1) Linearly dependent active sets: 180 minimal dependent subsets exist among the 21 filed condensates (diopside = wollastonite + enstatite; forsterite = 2 enstatite − quartz; any three Ti oxides), and admitting one makes the saturation-step matrix singular — garbage steps, then chronic evictions; a Gaussian-elimination dependence guard at activation (`COND_DEPCHECK`) now swaps a dependent candidate in for the combination member with the smallest condensed amount, so the active set stays independent by construction (GGchem's linear-combination elimination, adapted).  (2) Multi-phase slow-mode oscillations at phase handoffs: per-phase sign-flip damping (step halved per consecutive reversal) breaks period-2/3 cycles in a few outer iterations instead of waiting out the global 1/NOUTER damping; the outer cap rises 200 → 400 as backstop.  (3) A fully-condensed trace phase a hair *under*saturated (ln S ≈ −2×10⁻⁷, just outside the 10⁻⁷ tolerance) at its floored remnant cannot move and spun the loop to the cap: the exhaustion clamp is now sign-symmetric within |ln S| < 10⁻³.  (4) The exhaustion clamp's threshold referenced the arithmetic remnant floor (10⁻¹⁴·ε) rather than the depletion ceiling's remnant (10⁻¹²·ε) — so it could only ever fire for elements with ε ≲ 10⁻⁸ and structurally missed Ti, Ca, Mg, Si, Al, Fe (it had caught ZrO₂ by zirconium's abundance): CaTiO₃ as a layer's sole Ti sink pinned at ln S = +7.6 for 400 iterations at the Ti ceiling.  With all four fixes the 2500 K dwarf runs 30 iterations with 2 one-shot self-correcting evictions (from 2048 chronic warnings), at the flag-OFF pace, condensing-zone flux closure 0.03%, and a −25…−30 K condensation A/B over log τ ≈ −5.5…−4.0 at the true (unpinned) surface temperatures; the 2800 K dwarf shows −25…−42 K with zero warnings, the 2800 K giant trace-ZrO₂ only, and solar/3500 K remain bit-identical (condensation stays a per-layer T ≤ 2600 K + supersaturation decision — no Teff gate is needed, and warm models pay nothing). - Deep convection-zone convergence overhauled ("CZ constructor", `CZ_CONSTRUCT`): where convection is efficient the classical flux-error correction is structurally dead, so the required gradient is obtained by inverting the Böhm–Vitense relation in closed form for the superadiabatic excess carrying F_conv = F_tot − F_rad, applied as incremental interval-space corrections blended into the Kurucz correction by convective flux fraction. - Terminal deep-CZ polish (`CZC_POLISH`, developer flag `USE_CZC_POLISH`, default on): on the final iteration, the CZ-constructor block's temperatures are re-placed by a Newton solve of the node-gradient system ∇_j(T) = ∇_ad + ∇_required (tridiagonal finite-difference Jacobian, banded LU; the interval-sweep construction is retained as a fallback), closing the MLT flux relation against the final radiative flux to ≲0.1% where the iterative floor was 5–30%.  Two structural facts force this design.  First, deep-CZ flux balance is stiff: F_conv ∝ (∇−∇_ad)^{3/2} at ∇−∇_ad ≈ 10⁻³ demands milli-Kelvin temperature placement — three orders below the constructor's release threshold, and unreachable during the iterations because each TAUSTD remap re-perturbs T at the Kelvin level (which is also why deep-CZ flux errors of tens of percent are endemic to published cool-dwarf models).  Second, ∇_ad's rapidly varying curvature through the H₂-dissociation region (the EOS chain itself is smooth to ~10⁻⁷, verified by the fine-T probe `GRDADB_SCAN_MAYBE`, env `ATLAS_GRDADB_SCAN`) defeats interval-space constructions: the interval-slope vs node-average operator mismatch has an alternating component invisible to averaged relaxation, which DEL^{3/2} stiffness amplifies to ~16% flux error.  Two further constraints shape where and how the placement is applied.  The polish closes the *raw* MLT flux relation, which equals the model's actual (1-2-1 smoothed, gap-filled) convective flux only where convection is efficient, so its authority is a smoothstep in convective flux fraction over `CZC_POL_W_LO`…`CZC_POL_W_HI` (0.85…0.95): full in the deep interior — which contains the entire flux-balance sawtooth — tapering to zero at the CZ-top transition, which is left to the normal iteration.  (Applying it across the transition instead degrades those layers from <1% to several percent, and the final consistency refresh must likewise use the full production `CONVEC`, not the MLT-only path, or the `.atm` convective-flux columns are overwritten with raw MLT that switches convection off near τ≈1.)  And because re-placing the block in isolation shifts its temperatures — by several K where the constructor left the deep CZ far from closure — against a still-unrelaxed atmosphere above, the polish runs on the last `CZC_POL_NHEAL` (8) iterations rather than only the final one: between calls the normal flux correction, which is alive in the transition, relaxes those layers toward the polished deep boundary, healing the boundary seam (3500 K: 7% → a converged 1.8%, with the final polish then applying ≈0 ΔT).  Verified on 2500/2800/3500 K: the deep convection zone closes from ±11–34% to <0.04%, with the CZ-top transition left at a normal 1–2%; solar and hot-star models are untouched (the polish only runs where the constructor engaged).  A closure summary goes to the run log, the post-polish per-layer state is appended to `.iter` as a final block in the standard table layout (`ERROR` is the flux residual at frozen F_rad, `T1` the polish ΔT, correction columns zero by construction), and the final `.atm` carries the polished structure

- A SECOND stimulated-emission double count removed, this time in H₂⁻ free-free (`H2MINOP`), found during a continuum-budget audit of the residual 2700 K disagreement with PHOENIX.  The CIA entry above had explicitly exempted H₂⁻, on the grounds that Turbospectrum's `detabs.f` divides its H⁻ ff table by the global (1−e^{−hν/kT}) but leaves `fakt(22)` alone.  That inferred the convention from another code's *treatment* of the table instead of from the table itself, and it was wrong.  Applying the same low-frequency test that settled the CIA case — by Kirchhoff the true, stimulated-emission-corrected free-free coefficient is j_ν/B_ν, and since j_ν → const while B_ν → 2ν²kT/c², any correctly normalised ff table must go as ν⁻², i.e. k ∝ λ², where an uncorrected one would go as λ³ — John's real tabulated points (excluding Plez's own λ² extension at 210 µm, which would beg the question) give **p = 2.00 at all seven temperatures**, in a regime as deep as hν/kT = 0.05.  The Bell & Berrington (1987) H⁻ ff table gives the identical p = 2.00, and `HMINOP` has always treated that one as already corrected.  Two tables with the same asymptote cannot carry opposite conventions, so the STIM factor in `H2MINOP` was a double count worth 1/(1−e^{−hν/kT}) — 17% of H₂⁻ at 2.2 µm / 3400 K and 8% at 1.6 µm.  Turbospectrum appears to double count it for the same reason.  WHY IT MATTERS HERE: a per-source continuum decomposition (new `DUMP_CONTINUUM` developer flag writing `<model>.cont`, read by `tools/cont_audit.py`) shows that at 2700 K the H and K continua are carried by **H₂⁻ ff, not H⁻** — at the τ_cont = 1 layer the budget is H⁻ 30.3% / H₂⁻ 51.5% / CIA 12.0% / He⁻ 5.1% in the H window and 22.8 / 42.1 / 30.8 / 4.3 in K, against H⁻ ≈ 98% in the optical.  Removing the double count therefore raises the continuum opacity by +4.5% (H) and +7.1% (K) while leaving the optical, I and J windows untouched to ≤0.2% — the same wavelength signature as the residual it was found chasing.  Ruled out along the way, by measurement rather than assertion: the 2500–5000 K gap in John's temperature grid, which straddles the actual forming layers at 3379–3454 K, costs only 1.3% in k (≈0.6% in opacity); n(H₂) agrees between the opacity routines and NMOLEC to 0.5% there (both go through `EQUILH2`, which NMOLEC also uses for its own H₂ row, so the two cannot split as TiO once did); the CIA continuation above Abel's 3000 K box covers 21% of the H/K-forming layers but a deliberate factor-of-two costs 0.71%; and no continuum source is negative anywhere in 350–2500 nm.  Two provenance weaknesses stand recorded, neither yet acted on: John (1975) is a 10 λ × 7 T table and Bell (1980, J.Phys.B 13, 1859) is a later two-centre close-coupling calculation with exchange and polarisation describing itself as in only "fair agreement" with its predecessors — at a 42–52% opacity share that difference is the right size to matter; and `HEMIOP`'s He⁻ free-free (4–5% of the H/K continuum) is a bare polynomial inherited from the F77 with no citation at all, though its own low-frequency limit does go as ν⁻², so its stimulated-emission convention at least is right. That is far less than the line-count jump suggests, because the additional Toto lines are overwhelmingly weak while the strong bands that set the opacity are saturated in both lists.  The spectra were already correct — what this fixes is the structure being built on a different absorber from the spectrum computed on it.  `schwenke.bin`, the superseded `mol/tiototo.bin`, and `h2ofastfix.bin` (retired earlier by POKAZATEL) are no longer referenced by either code

## Data and code hygiene

- Far-infrared tails trimmed from the four ExoMol-converted molecular line files.  The Kurucz molecular ASCII wavelength field is `F10.4`, which cannot hold 100000 nm: a longer wavelength shifts every subsequent field and the reader rejects the whole record.  `tools/exomol_to_kurucz.py` had no wavelength ceiling, so `cah_owens22.dat` (615 lines), `mgh24/25/26_owens22.dat` (1003/995/1006) each ended in a block of unreadable records — reported by `read_one_diatomic_ascii` as skipped malformed lines on every ATLAS12 run since those lists became default.  They were wavelength-sorted contiguous tails of pure-rotational X-state transitions between 100 µm and 970 µm, so nothing inside the modelled flux was affected and removing them is bit-identical to the skipping the reader was already doing.  Files truncated in place (removed tails staged in `~/kurucz/superseded_linelists/gt100um_tails/`), and the converter now drops anything beyond `WL_FMT_MAX = 99999.9999` nm with a printed count, so regenerated lists cannot reintroduce it.  Kurucz's own hand-made files are unaffected: `hdxx.dat` carries its four >100 µm lines as `103330.`, dropping decimals to stay inside the field
- Hardcoded data arrays (partition functions, Feautrier matrices, Karzas–Latter tables, ionization potentials, isotope fractions) externalized to readable data files
- Dead-code audit with static call-graph analysis: ~233 lines removed from `atlas12_modules.f90`
- He I line-profile island (`HE1_GENERIC_PROFILE` and 11 helpers, ~904 lines) retained but marked `PORT INCOMPLETE` and not currently called; `stark_quasistatic_profile` handles He I until that port is completed
- All remaining Fortran 2008 `BLOCK...END BLOCK` constructs eliminated
- All routines carry descriptive header comments
