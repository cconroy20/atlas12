# ATLAS12 + SYNTHE — Modernization Ledger

The complete record of the translation from Robert L. Kurucz's Fortran 77
originals: every structural, numerical/physical, and hygiene change, with
design rationale, validation numbers, and post-mortems.  A compact
current-state summary lives in the README ("Translation from Fortran 77"
section); open items are tracked in [atlas_to_do.md](atlas_to_do.md).

Entries within each section are in rough chronological order.  Where a
later entry revisits an earlier one (e.g. a flag default changed after
further hardening), the later entry stands.

## Structural

- Free-format Fortran 90 source; explicit typing throughout; `-r8` flag removed
- 58 COMMON blocks consolidated into two modules (`mod_parameters`, `mod_atlas_data`)
- 829 EQUIVALENCE statements eliminated
- Full GOTO elimination pass: 38 → 0 active GOTOs across all four files, including a refactor of the `JOSH` radiative transfer solver
- Command-line argument parsing replaces card-based input for ATLAS12 driver options
- The `mklinelist` line-list preprocessor (formerly the standalone `synbeg | rgfall | rpredict | rmolecasc | rh2ofast` shell pipeline) absorbed into the SYNTHE executable as `mod_mklinelist`, dispatching from a single plain-text `lines.list` manifest
- SYNTHE three-program pipeline (XNFPELSYN, SYNTHE, SPECTRV) merged into a single executable with all inter-stage data flow in memory; intermediate binary scratch files (`fort.9`, `fort.10`, `fort.13`, `fort.14`, `fort.15`, `fort.93`, `spectrv.input`) eliminated
- ASCII spectrum output written directly by SYNTHE (`.spec`), eliminating the standalone `syntoascanga` post-processing step

## Numerical and physical

- Atmosphere state arrays (T, P, ρ, χ, populations) promoted from REAL(4) to REAL(8)
- Physical constants consolidated into `mod_constants` with CODATA 2018 values, replacing ~130 scattered literals
- Atomic partition functions replaced with the Barklem & Collet (2016) tabulated U(T) calculated by direct NIST level summation, covering Z = 1..92 in ionization stages I–III; the legacy Kurucz hand-selected few-term sums used by `PFGROUND` (the low-T floor in `PFSAHA`) and the generic `NNN` interpolation table are retained as an internal safety net but are no longer the production data source.  Iron-group partition functions (Z = 20..28) still flow through `PFIRON` for its pressure-lowering correction, but the unperturbed POTLOW = 0 baseline is now anchored to B&C
- Metal continuum bound-free opacity overhauled: a new `CONT_METAL_OPACITY_TOPBASE` dispatcher replaces the legacy collection of analytic Seaton/Peach fits (Li1OP, C1OP, MG1OP, AL1OP, SI1OP, FE1OP, …).  `MBF_TOPBASE` supplies 30 species (neutrals and first ions of Li, Be, B, C, N, O, F, Ne, Na, Mg, Al, Si, S, Ar, Ca) from R-matrix Opacity Project cross sections processed by Allende Prieto, Hubeny & Lambert (2003, ApJS 147, 363) into resonance-averaged 3%-log-spaced grids; `MBF_HIGH_ION` supplies higher ionization stages and Coulomb free-free from a filtered subset of `hotop.dat`; `FELO_OPACITY` supplies Fe I and Fe II from Iron Project / Opacity Project R-matrix calculations (Bautista 1997 for Fe I, Nahar & Pradhan 1994 for Fe II, sourced from the TLUSTY model atoms).  Toggleable via `USE_TOPBASE_MBF`; the legacy path is preserved for reference.  Known limitation: TOPbase identifies levels by LS term without resolving J, so per-species opacity carries a U_TB/U_BC factor of a few percent for most species (≲13% for the worst case, Ar II)
- Solar reference abundance pattern is now selectable at the command line (`solar=name`).  The compiled-in default remains Anders & Grevesse (1989), defined once in `mod_atlas_data` and shared by ATLAS12 and SYNTHE; `solar=` replaces the abundance table carried by the input model file while preserving its relative [M/H] offsets, and `zscale=`/`abund=`/`heabnd=` overrides apply on top.  Additional named scales are stored as log-ε tables and converted internally (`LOGEPS_TO_ABUND`); registered scales: `ag89` (Anders & Grevesse 1989), `agss09` (Asplund et al. 2009), `berg25` (Bergemann, Lodders & Palme 2025, with A(He) = 10.922 from the published compilation).  (An earlier changelog entry here claimed the default had been switched to Asplund et al. 2009 — that change was never made; the code default has always been AG89.)
- Hydrogen line profiles now use the Stehlé & Hutcheon (1999) MMM tabulated Stark broadening profiles via `hydrogen_line_profile`, replacing the Kurucz–Peterson (1982) analytic approximation; the K–P path is retained as a fallback for atmospheric layers exceeding the Inglis–Teller density limit, controlled by the `USE_KP_HYDROGEN` flag
- Voigt function evaluated via Weideman (1994) N=32 rational approximation of w(z) plus Humlíček (1982) R₁,₂ asymptotic, replacing the Kurucz three-regime table approximation that had ~4% error at the a = 0.2 regime boundary.  Accuracy is now ~10⁻⁵ relative across the full (a, v) plane with no regime boundaries
- The H⁻ bound-free photodetachment cross section in `HMINOP` replaced: the Mathisen (1984) / Wishart (1979) / Broad & Reinhardt (1976) 85-point table is superseded by McLaughlin, Stancil, Sadeghpour & Forrey (2017, J. Phys. B 50, 114001), resampled onto 116 points.  The old table ran ~0.1–1.4% high through the optical (growing toward 8000–9000 Å); the swap removes a ~1% optical continuum offset against Korg, which adopts the same source (the free-free table — Bell & Berrington 1987 — was already common to both codes, isolating the difference to the bound-free data).  The resampling reproduces the smooth optical/IR continuum to <0.05% under the code's own MAP1 interpolator; the narrow far-UV Feshbach resonance (113.4 nm, ~0.02 nm wide) is deliberately represented by its broad envelope only — a table fine enough to resolve it would ring under MAP1, and it is negligible for the continuum.  The non-LTE H⁻ polynomial in `STATEQ` is untouched (the non-LTE branch is unused in production).  Below the free-free table's 1400 K edge, `HMINOP` extrapolates linearly in θ = 5040/T — verified against the table's own curvature to ≤2% at 1200 K and ≤7% at 1000 K; a literature check found no replacement source at stellar temperatures (the Schleicher et al. 2008 low-T fit runs ~40% high)
- H₂ partition function read from an external data file rather than hardcoded
- The `JOSH` scattering solution is now a direct dense solve of the 51-point integral-operator system (I − diag(α)·Λ_J)·S = (1−α)·S̄ via `SOLVIT`, replacing the Gauss–Seidel Λ-iteration.  The iteration stalled against its 50-sweep cap once the scattering albedo α exceeded ~0.99 across the grid — 0.3% error in S at α = 0.99, 10% at α = 0.999, accepted after a warning — and its 10⁻⁵ early-exit tolerance quantized the response of every scattering solve, leaving discontinuous noise in H_ν at the tolerance level.  The direct solve is exact at comparable cost (one 51×51 LU per frequency) and reproduces the iteration to its own tolerance wherever the iteration converged (`workdir/pfverify/josh_verify.py`, Test D)
- Optional Steffen (1990) monotone-cubic quadrature for `INTEG` (developer flag `IQUAD = 1` in `mod_atlas_data`), the routine that builds τ_Ross, the per-frequency τ_ν, P_rad, and the height scale.  The legacy blended-parabola quadrature (`PARCOE`) integrates a 5-decade exponential on real model grids with 1.3% (solar) to 11% (2800 K) maximum error — only ~2× better than a trapezoid — while the Steffen cubic is 3–6× more accurate and its monotone interpolant keeps τ scales monotone with no overshoot (`workdir/pfverify/josh_verify.py`, Test C).  The quadrature error is concentrated in the deepest layers, so switching moves converged structures mainly at the grid bottom: ≤1.5 K in cool/warm stars (convection pins the deep adiabat) but 0.1–0.5% of T in hot-star radiative envelopes (47–105 K at 8000–40000 K), with equal convergence quality and negligible emergent-flux change.  The default remains the legacy quadrature
- Partition-function tables (H₂ and Barklem & Collet) evaluated with natural cubic splines instead of (log-)linear interpolation.  The interpolation kinks at table nodes, sampled by the EOS finite-difference stencil, imprinted spurious structure on ∇_ad that F_conv ∝ (∇−∇_ad)^{3/2} amplified into large local flux errors in cool-dwarf deep convection zones.  Node values, boundary behavior, and hot-star fallbacks are unchanged (verified by the `workdir/pfverify/` battery); converged structures shift by ≲0.5 K
- Molecular equilibrium network extended and repaired.  The species list (`molecules.dat`) gains ten diatomics — CrO, CrS, TiN, TiS, TiH among existing network elements, then ScO, YO, ZrO, LaO, MnH with Sc, Mn (ion stages I–V) and Y, Zr, La (I–III, the generic partition-function path's limit) as new network elements — refit from Barklem & Collet (2016) Table 7 equilibrium constants in the same physical-form basis as the existing "BC16 fit" rows via the new `tools/fit_molecule_keq.py`, kept in-repo so the fit provenance survives with the data (its `--validate` mode regenerates all 41 pre-existing neutral-diatomic BC16 rows exactly).  Li, Be, and B — previously in the network only as neutrals bound in LiH/BeH/BH, with no ionized sink in element conservation — gain ionization stages I–III.  The Y I and Zr I ionization potentials in `ionpots.dat` are corrected against BC16 Table 4 / NIST (both were ~0.2 eV high, a ~2× overestimate of the neutral fractions at 3500 K), and the `READMOL` species-code decoder now peels digit pairs in integer arithmetic — the old real-valued rounding misread any trailing pair ≥ 50, first triggered by La (LaO = 857.00 decoded as 9, −43).  The Ti/Cr additions are EOS completeness (solar flux bit-identical; ≲0.5% broadband shifts at 2500–3500 K, where TiH depletes deep-layer TiO by ~2%), but the s-process oxides change cool-star chemistry qualitatively: ZrO, LaO, and YO lock ≳99.9% of their elements in the 2500 K photosphere (92–99% at 3500 K), collapsing neutral Zr I / Y I / La I resonance lines — previously computed with the full element atomic — by up to 10⁴ in the blue/UV; and Mn, 94% ionized at solar conditions, joins the charge balance, correcting a ~0.1% electron-density deficit.  That last mechanism generalizes — under molecular equilibrium (`IFMOL=1`, the production path) the charge-conservation equation sums network species only, so elements absent from `molecules.dat` contribute nothing to n_e (a Kurucz-era design gap: the deck's atom list was "elements that form molecules", and `NELECT`, which does sum Z = 1–30, is reachable only with molecules off).  Co, Ni, Cu, and Zn therefore enter as pure atom/ion rows (Co/Ni I–V via `PFIRON`, Cu/Zn I–III via the generic path; Co I's ionization potential corrected 63400 → 63565 cm⁻¹ on entry), recovering a Ni-dominated +0.5–0.7% n_e through the solar line-forming layers.  The solar photosphere responds by cooling 1–3 K around τ ≈ 1 (the H⁻ opacity increment), moving blue/UV flux by ~0.1% typically and 1%+ in the strongest-blanketed 1300–6600 Å line cores; cool dwarfs are nearly untouched (Ni stays neutral at 2500–3500 K until the deep layers).  Phosphorus then enters (P I–VI; PH, PN, PO, PS, P₂, CP from BC16 — at 2500 K it partitions ~49% atomic / 24% PH / 19% PO) together with the metal halides (LiF, NaF, MgF, AlF, KF, CaF, LiCl, MgCl, AlCl, NaCl, KCl, CaCl): fluorine's secondary reservoir is AlF at ~14% (HF 86%), chlorine stays 99% HCl, and alkali-halide sequestration of Na/K proves negligible down to 2500 K, so solar and cool-dwarf structures are essentially unchanged (max |dT| ≤ 0.05 K).  A final completeness pass adds KH, NiH, CoH, CuH, ZnH, ScS, YS, LaS, NaO, KO, SiF, SiCl, SF, and the Be/B families (BeO, BeF; BO, BF, BN, BS): boron turns out to be ~99.9% BO at 2500 K — its 2090 Å resonance doublet was previously computed fully atomic — while every other budget shifts by <1% (KH 0.3% of K, NiH 0.9% of Ni) and structures are unchanged.  The polyatomic legacy rows were then audited against NIST-JANAF (via the kp compilations shipped with GGchem, Woitke et al. 2018): 10 of the 12 with no ExoMol coverage agree to ≤0.09 dex — Kurucz's polyatomics trace to the same JANAF-era thermochemistry — while the two outliers got deliberate D0-consistent refits (MgOH: JANAF Kf shape with the Koput 2023 D0 = 7.581 eV, a real 0.4 eV Mg–OH bond conflict with JANAF's 7.981; HO₂: Stock/Kitzmann shape with the ATcT D0 = 7.198 eV, replacing a never-updated 7.108).  Five JANAF-route polyatomics were added — TiO₂, VO₂, AlOH, Al₂O, AlO₂H — with the largest spectroscopic consequence of the whole revision: at Teff = 2500 K, TiO₂ holds ~23% of Ti in the upper photosphere (TiO drops ~19%) and aluminium goes majority-molecular (AlOH 53%, Al₂O 36%), moving the TiO-banded optical by a median ~12% (5000–7000 Å) with a 2.3 K structure response, while the 1–2.5 μm flux carrier and all warmer models are essentially unchanged (solar bit-identical) — late-M TiO bands were systematically too strong before — gas-phase TiO₂ has been in the standard cool-star equilibria since Tsuji (1973) and at modern JANAF strength in Sharp & Huebner (1990), the declared polyatomic source of the PHOENIX EOS.  The ExoMol-route additions followed: KOH, LiOH, HBO, SiH₂ assembled from ExoMol partition functions with independently sourced dissociation energies (JANAF chains for the hydroxides; Berkowitz & Ruscic 1987 for SiH₂, whose Stock/Kitzmann entry still carries the stale pre-1987 silylene enthalpy; JANAF + the ATcT boron atom for HBO), and PH₃ as a Stock/Kitzmann-shape fit with the D0 swapped to the JANAF/CCCBDB value (the PH₃ table shipped in the GGchem JANAF folder is corrupt, and ExoMol's PH₃ partition function stops at 400 K).  At 2500 K the boron budget flips — HBO holds 94–99.5% of B, displacing BO — and PH₃ becomes the leading phosphorus hydride (PH₃/PH ≈ 3.5–7); potassium and lithium hydroxides stay trace above the brown-dwarf regime, and solar models are again bit-identical.  Finally, the molecular-ion rows were repaired: the April refit had fit the 8 BC16 ion rows in BC16's dissociation convention (atom + ion⁺) rather than the electron convention NMOLEC implements (K = n(M⁺)n_e/Πn(atoms)), underproducing molecular ions by 4–13 dex — with no observable consequence, since H₂⁺ opacity is computed from n(H)·n(H⁺) directly — and all 8 are refit with the Saha factor restored (now 0.0–0.6 dex from Kurucz's originals, which had the convention right); H₃⁺ is upgraded from the legacy polynomial (itself ~4.5 dex low) to an ExoMol MiZATeP assembly with a spectroscopic E1 = −4.771 eV, and `fit_molecule_keq.py --validate` now covers every diatomic in the file: 96/96 exact.  The network now carries 297 rows, 33 equilibrium equations (`maxeq` raised to 50).  The complete April 2026 fit pipeline now lives in `tools/` (`comp_pf.py`, `build_molecules_physical_dat.py`, `kurucz_molec.py`, and the six data modules that had been lost after that refit, reconstructed and validated by reproducing the April `molecules.dat` to 188/190 rows at printed precision — which pinned the ExoMol nuclear-spin convention and recovered the full-precision assembly D₀ values).  The fit atlas `comp_pf.pdf` is regenerated by it in the original convention — Kurucz original/updated polynomials against BC16 (diatomics) and ExoMol-assembled (polyatomics) references with the physical-form fits and residuals — including one page for every species added in July 2026 (diatomics against BC16; new polyatomics against NIST-JANAF/Stock-Kitzmann) and JANAF reference overlays on the legacy self-fit pages; the untouched April original is preserved as `comp_pf_apr2026.pdf`
- Departure-coefficient machinery for selected lines in SYNTHE (`mod_nlte`, developer flag `NLTE_MODE` in `mod_parameters`, default 0 = pure LTE): scaffolding only — no departure coefficients ship, and mode 2 (read from `<model>.dep`) is not implemented.  SYNTHE is an LTE synthesizer, and its transfer step is handed one line source function per depth per wavelength, `SLINE = B_nu`; that is wrong for resonance lines of minority species, most sharply for the alkalis (Olander et al. 2021, A&A 649, A103, measure −0.06 to −0.37 dex NLTE corrections on the K I resonance lines in M dwarfs, driven by photon losses that overpopulate the lower level).  Kurucz anticipated the correction — `gfall` reserves NBLO/NBUP columns, `read_gfall` routes any record carrying them into the `nlte_lines` pool, and `CODEX` whitelists 17 species including Na I — but the preprocessor that filled them (RNLTE, which folded the b-factors into GF) was never part of this port, so the hook has always been dead.  Given `b_l`, `b_u` and `x = h nu_0/kT`, the line opacity becomes `kappa_LTE * b_l * [1 − (b_u/b_l)e^−x]/[1 − e^−x]` and the source function `(2h nu^3/c^2)/[(b_l/b_u)e^x − 1]`, both exact rather than Wien-limit; these multiply to the identity `kappa*S = b_u * kappa_LTE * B_nu * (1 − e^−x)`, i.e. the line emissivity is simply `b_u` times its LTE value.  That identity is what makes the retrofit cheap: SYNTHE accumulates one summed line opacity per (lambda, depth), so all that has to be tracked alongside it is the opacity-weighted *deviation* of the emissivity from LTE, which vanishes identically for every LTE line.  The implementation adds one `(length, nrhox)` accumulator — allocated only when NLTE is active — and `SLINE` becomes `BNU * (opacity + deviation)/opacity`, which is automatically the correct opacity-weighted mean where an NLTE line blends with LTE neighbours.  `JOSH` is untouched: its `SNUBAR = (ACONT*SCONT + ALINE*SLINE)/(ACONT + ALINE)` was already the right form.  Eligible transitions are declared in `mod_mklinelist` and matched on species plus *both* level energies rather than wavelength, so every hyperfine component of a multiplet is tagged with one pair of departure coefficients (Na I D2 has six components in `gfall`, D1 four, via the `iso1=23`/`x1` relative-log-gf mechanism); `read_gfall` records the tags unconditionally, exactly as it records `ICA4227`, and SYNTHE's line loop resolves membership with a single advancing cursor over the sorted tag list — two integer compares, and one logical compare when the flag is off.  Validation, solar model and a 3000 K/log g 5.0 dwarf over 5870–5920 Å at R = 3×10⁵: (i) `NLTE_MODE = 0` reproduces the pre-change binary bit for bit, and `atlas12c.o` compiles byte-identical (ATLAS12 imports only `read_diatomics_for_atlas`/`get_mol_bin_path` and never enters `read_gfall`); (ii) the null test `NLTE_MODE = 1, b_l = b_u = 1` is *also* bit-identical while exercising every line of the new path — the factors collapse to exactly 1.0 and 0.0, not to within rounding, because `1 − beta e^−x` and `1 − e^−x` become the same expression and `y/y` is exactly 1 in IEEE arithmetic; (iii) the opacity path, tested with `b_l = b_u = 10^0.3` against an independently rebuilt `gfall` carrying `log gf + 0.300` on exactly those ten records, agrees to 1.7×10⁻⁶ in relative flux — the residual is the REAL(4) `gflog` storage, not the NLTE code; (iv) the source-function path, tested with `b_l = 1` and `b_u = 0.5`/`0.25`, darkens the saturated cores by 0.4994/0.2496 (solar) and 0.5000/0.5000 (M dwarf) against the analytic saturated-core limit `b_u/b_l`; (v) both changes are exactly zero outside the doublet's own truncated wing, and a window containing no eligible transition reports and falls back to LTE.  A second test shape (`NLTE_TEST_SHAPE = 1`) closes what the constant one structurally cannot: shape 0 writes the SAME number into every element of b, so a wrong (transition, depth) index, a reversed depth axis, or coefficients attributed to the wrong line all still produce exactly the right answer — and would first surface in mode 2, indistinguishable from bad grid data.  Shape 1 ramps b linearly in log10(column mass) (the variable an external grid must be interpolated on) between a deep value of 1, where collisions enforce LTE, and per-transition surface values chosen so that b_l /= b_u, b_l /= 1, and D1 /= D2.  Every NLTE run now also writes `<model>.nlte`: one row per (transition, depth) carrying the depth scale, the installed b, and the factors `nlte_factors` ACTUALLY returned — recording the returned values rather than re-deriving them is what lets the dump catch an indexing error inside `nlte_factors` and not only one in `fill_departures`.  `tools/nlte_check_dump.py` differences it against the profile it should have come from: installed b vs an independent evaluation of the ramp, returned fkappa/fdev/S_l/B_nu vs the equations, and the identity fkappa*(1+fdev) = b_u, all agreeing to 5e-15 on both stars (the dump is written at full double precision on purpose — a 5-digit dump had put a 1e-6 floor under exactly these comparisons).  At flux level the structured shape adds two checks the constant one cannot pose: each saturated core moves to its OWN surface S_l/B_nu rather than the other transition's (solar D2 0.570 against its own 0.500 vs D1's 0.727; M dwarf D1 0.7273 against its own 0.7273), and the response decays from core to wing (frac 0.86 -> 0.09 solar, 0.88 -> 0.32 in the M dwarf, where even the 8 A wing is still optically thick) — a reversed depth axis inverts that ordering.  The population-inversion guard, never exercised before, was fired with b_u/b_l = 20 and brackets its analytic threshold exactly: x = 2.9194 among inverted depths < ln 20 = 2.9957 < x = 2.9973 among the rest, with the affected layers forced back to LTE.  `mod_nlte` also compiles clean under `-fcheck=bounds` (against an -O3 remainder) on both stars.
- Bit-identity caveat for the above, measured rather than assumed: `NLTE_MODE = 0` reproduces the pre-change binary exactly on the Sun, and on a 3000 K dwarf it differs at 2 of 2544 points by one unit in the last PRINTED digit (~4e-7 of the local continuum).  Rebuilding both with `-ffp-contract=off` makes them bit-identical, which identifies the cause as FMA contraction changed by the restructuring, not a change in the physics.  The NLTE source function is applied in its own guarded loop rather than as a fourth factor on the LTE `SLINE` expression, so the production expression stays textually untouched; that was not sufficient to remove the contraction difference on its own, but it is the right structure and the mode-1 null test (which compares against mode 0 of the SAME binary) is bit-identical on both stars.
- Latent bug fixed in `interp_logu_cached` (Barklem & Collet partition-function bracket search): the "moved up"/"moved down" hint tests were written as single `.AND.` chains with the range guard first — `LO+1 < NT_BC .AND. T >= T_GRID(LO+1) .AND. T < T_GRID(LO+2)` — which only avoids reading past the array if `.AND.` short-circuits, and Fortran leaves operand evaluation order to the compiler.  At -O3 gfortran happened to short-circuit so the read never occurred; at -O0 with `-fcheck=bounds` it evaluates both operands and aborts on `T_GRID(43)` of a 42-element grid, which made any bounds-checked build of the code unrunnable.  The guards are now evaluated into logicals first, which does not depend on evaluation order; spectra are bit-identical across the change.  A SECOND pre-existing bounds violation remains unfixed and still blocks a whole-program `-fcheck=all` build: `number` in `atlas12_modules.f90` is indexed at 2 in a dimension of extent 1.  That one is not obviously an evaluation-order artifact and deserves a separate look.
- `NLTE_MODE = 2` implemented: departure coefficients from a `<model>.dep` sidecar, looked for next to the model file (b belongs to a structure, so the two travel together).  Free-form text — `NTRANS`, `NDEPTH`, optional `DEPTHVAR LOGRHOX`, then one row per depth of `log10(rhox)` and `b_lo b_up` per transition, surface first — interpolated linearly in `log10 b` against log10 column mass.  Outside the table the endpoint value is HELD rather than extrapolated (departure coefficients turn over sharply at the top of an atmosphere and a linear continuation there produces confident nonsense); clamped layers are counted, warned about, and flagged with a `clm` column in the `.nlte` dump, so that "the grid did not cover this model" cannot be mistaken for "the interpolation is broken".  Reading the grid binaries themselves was deliberately kept OUT of SYNTHE: `tools/nlte_make_dep.py` does the grid I/O, stellar-parameter selection, depth-scale conversion and level mapping, and SYNTHE reads one small self-describing file — the alternative buries two lines of physics under several hundred lines of a format that is reissued periodically.  The real work in that tool is the depth scale: the published grids are tabulated against tau_5000, which an ATLAS12 `.atm` does not carry (it has RHOX exactly and ABROSS, so column mass is exact and tau_Ross derivable, but not tau_5000) — and converting through *our* tau would be wrong regardless, since optical depth depends on continuum opacity and equating it across codes equates layers at different physical conditions, the failure that once faked a 440 K offset against PHOENIX at 2700 K.  So the tool converts tau_5000 to column mass through the MARCS model the grid was actually solved on, which tabulates lgTau5 and RHOX on the same layers; `--marcs` is therefore required, not a convenience.  Level indices must be stated (`--levels`) or matched by term energy against a model atom (`--atom`), and the tool refuses to proceed on an ambiguous match rather than silently produce a plausible, wrong spectrum.  Validation: `--selftest` fabricates an index, a stream binary and a MARCS-like model in the documented layouts and round-trips the whole path (depth column recovered to 1.7e-6 dex — the floor set by MARCS's 6-digit RHOX, not by the tool; b columns exact; correct model selected among two candidates); the sidecar it writes is then read straight back by SYNTHE end to end.  The decisive check on the Fortran side is a round trip against the harness: a sidecar sampled on a model's OWN layers carrying the `NLTE_TEST_SHAPE = 1` ramp reproduces the mode-1 shape-1 spectrum BIT-IDENTICALLY on both the Sun and a 3000 K dwarf — same b, entirely different route in — which tests reader, header parsing, interpolation and level mapping as one chain.  Interpolation was separately verified against an independent Python evaluation on a deliberately coarse 11-node table (70 of 72 model layers fell strictly between nodes; max |db| = 4.9e-15), clamping against a table deliberately 1.2 dex narrower than the model on both sides (15 layers above and 31 below flagged exactly, endpoint values held, none wrongly flagged), and seven malformed-input paths each produce a specific diagnostic.  The binary and index layouts follow Turbospectrum's own reader (`utilities/read_nlte_grid.py` in TSFitPy, `interpolator/interpol_modeles_nlte_gfort.f` in Turbospectrum_NLTE); the tool has NOT yet been run against a downloaded grid, and the printed level assignment and depth span should be checked the first time it is.
  Data source for mode 2 is the Amarsi et al. (2020) MARCS departure-coefficient grids (3000–8000 K, Na included), repackaged by Gerber et al. (2023) for Turbospectrum.
- `tools/nlte_extract_grid.py`: one-pass extraction of a published NLTE grid's low-lying levels, so the download is paid once instead of per model.  Deflate is not seekable, so reaching a record costs decompressing everything before it — fine once, absurd 7000 times.  Two properties of the format make a single pass cheap, both verified against the index before use: records are FIXED STRIDE (all 436 254 pointer gaps identical at 130 876 B, so it is a state machine and not a search), and the wanted levels sit at the FRONT of each record (the departure block is Fortran-order (ndep, nlev), so level k is a contiguous run at offset k*ndep, and levels 1..N are a head read).  Applied to Na I: 32.6 min, 15.90 GB streamed, a few hundred kB of working memory, out comes 1.0 GB in `~/kurucz/nlte_grids/na/` holding tau_5000 and b for the 10 lowest levels at all 436 255 nodes — a 53x reduction that still covers Na D (1-3, 1-2), the 8183/8195 IMF-sensitive doublet (2-5, 3-5) and the 1.14 um pair (2-4, 3-4).  Ten levels rather than the three Na D needs because redoing the pass costs another full download while storage is linear and small.  Validated: the three records streamed individually earlier reproduce EXACTLY from the store; tau and levels 1-10 are exactly float32-representable in the source, so the store is lossless rather than a downsample; and a full scan of all 436 255 records finds 0 non-finite values, b in [3.5e-3, 5.2e7], tau in [5.1e-8, 3.4e2] and tau monotonic throughout.  One trap recorded for anyone extracting more levels: the HIGH levels of the source are not clean — the three records checked carry 2324, 6034 and 8202 non-finite values across the full 290-level block, while levels 1-10 are finite everywhere.
- `NLTE_MODE = 3`: departure coefficients interpolated straight from the extracted grid inside SYNTHE, with no per-model sidecar — the production path for grid runs.  Two prerequisites landed with it. - Deep convection-zone convergence overhauled ("CZ constructor", `CZ_CONSTRUCT`): where convection is efficient the classical flux-error correction is structurally dead, so the required gradient is obtained by inverting the Böhm–Vitense relation in closed form for the superadiabatic excess carrying F_conv = F_tot − F_rad, applied as incremental interval-space corrections blended into the Kurucz correction by convective flux fraction. - Terminal deep-CZ polish (`CZC_POLISH`, developer flag `USE_CZC_POLISH`, default on): on the final iteration, the CZ-constructor block's temperatures are re-placed by a Newton solve of the node-gradient system ∇_j(T) = ∇_ad + ∇_required (tridiagonal finite-difference Jacobian, banded LU; the interval-sweep construction is retained as a fallback), closing the MLT flux relation against the final radiative flux to ≲0.1% where the iterative floor was 5–30%.  Two structural facts force this design.  First, deep-CZ flux balance is stiff: F_conv ∝ (∇−∇_ad)^{3/2} at ∇−∇_ad ≈ 10⁻³ demands milli-Kelvin temperature placement — three orders below the constructor's release threshold, and unreachable during the iterations because each TAUSTD remap re-perturbs T at the Kelvin level (which is also why deep-CZ flux errors of tens of percent are endemic to published cool-dwarf models).  Second, ∇_ad's rapidly varying curvature through the H₂-dissociation region (the EOS chain itself is smooth to ~10⁻⁷, verified by the fine-T probe `GRDADB_SCAN_MAYBE`, env `ATLAS_GRDADB_SCAN`) defeats interval-space constructions: the interval-slope vs node-average operator mismatch has an alternating component invisible to averaged relaxation, which DEL^{3/2} stiffness amplifies to ~16% flux error.  Two further constraints shape where and how the placement is applied.  The polish closes the *raw* MLT flux relation, which equals the model's actual (1-2-1 smoothed, gap-filled) convective flux only where convection is efficient, so its authority is a smoothstep in convective flux fraction over `CZC_POL_W_LO`…`CZC_POL_W_HI` (0.85…0.95): full in the deep interior — which contains the entire flux-balance sawtooth — tapering to zero at the CZ-top transition, which is left to the normal iteration.  (Applying it across the transition instead degrades those layers from <1% to several percent, and the final consistency refresh must likewise use the full production `CONVEC`, not the MLT-only path, or the `.atm` convective-flux columns are overwritten with raw MLT that switches convection off near τ≈1.) ATLAS9/ATLAS12 carry H⁻ bf/ff, H₂⁺, He⁻ ff, H₂ Rayleigh and (once the previous entry restored them) H₂–H₂/H₂–He CIA, but never H₂⁻ + photon → H₂ + e⁻, which is standard in the MARCS family and matters wherever hydrogen is molecular: at 2700 K, log g 5 the models have n(H₂)/n(H I) ≈ 3–10 through the line-forming layers and ≳10³ above them, while the per-particle coefficient is ~0.4 of H⁻ ff, so H₂⁻ is the larger of the two free-free terms there.  Data: John (1975, MNRAS 172, 305) as tabulated for MARCS (Turbospectrum's `jonabs` entry, 10 wavelengths × 7 temperatures with Plez's long-wavelength λ² extension at 210 µm), transcribed as a PARAMETER table with bilinear interpolation in (log λ, log T), power-law extrapolation off the blue end and clamping in T. The call sits next to `HMINOP` in the main opacity driver, deliberately NOT inside the metal-continuum routine whose reorganization dropped the CIA. - COLLISION-INDUCED ABSORPTION MODERNIZED, and a stimulated-emission double count removed.  Three separate defects were carried by the shipped `H2COLLOP`.  (1) CONVENTION: the CIA tables already contain the (1−e^{−hν/kT}) factor, and the routine multiplied by `STIM` again.  Turbospectrum's `detabs.f` states it outright — "Aleksandra Borysow me signale que stim deja inclu dans CIA" (16/01-1996, on Borysow's own advice) — and divides every CIA term by its global factor to cancel it; independently, the low-frequency limit of all of these tables goes as ν² (measured slope 2.00 below ~50 cm⁻¹), the signature of a coefficient already carrying that factor, where without it the limit would be ν¹.  The double count suppressed CIA by 4–20% through the H and K windows at 2000–4000 K and by more than a factor of two in the rototranslational band, which weights the Rosseland mean.  Note this does NOT apply to H₂⁻ free-free (`fakt(22)` in detabs, absent from its `/stim` list), so `H2MINOP` is unaffected and correctly keeps its STIM. **[SUPERSEDED — see the next entry: the same ν² test, applied to John's table rather than to detabs's treatment of it, shows H₂⁻ was double counting too.]**  (2) DATA: Borysow, Jørgensen & Zheng (1997) replaced by Abel, Frommhold, Li & Hunt 2011 (H₂–H₂) and 2012 (H₂–He), taken from HITRAN's recommended "Main" set — the same tables PHOENIX runs under `USE_HITRAN_CIA=T`.  Abel et al. are one uniform ab initio calculation over the whole domain, replacing tabulations that "used different approximations and potential surfaces for different temperature and frequency ranges" (Saumon, Marley, Abel, Frommhold & Freedman 2012, ApJ 750, 74, §2.1), and agree with experiment where it exists (T ≤ 300 K).  The generator reproduces that paper's published Abel/Borysow comparison — H₂–H₂ fundamental band weaker by 24% at 1000 K and 44% at 2000 K — to three significant figures (0.753, 0.561) directly from the raw files, which is how the cm⁵ ↔ cm⁻¹ amagat⁻² conversion was validated rather than assumed.  (3) GRID: the shipped 7 × 81 table (T at 1000 K spacing, ν at 250 cm⁻¹) cost 11% rms and 82% peak interpolation error against the native tables, dominated by the sharp H₂ fundamental at 4160 cm⁻¹ — larger than some of the data differences it was being used to study.  The new file is 25 cm⁻¹ in ν and ~100 K in T, holding that to 0.03% rms / 0.4% peak.  TWO NEW PAIRS: H₂–H (Gustafsson & Frommhold 2003) and H–He (Gustafsson & Frommhold 2001), neither ever present in the Kurucz lineage, each behind `USE_CIA_PAIR` in `mod_atlas_data`.  Both are small — together 0.17% of the K-window continuum at 2700 K — but they cost nothing and the framework now carries them.  H₂–H2 CONTINUATION: Abel's H₂–H₂ box stops at 3000 K and 10⁴ cm⁻¹ while ATLAS12 runs to 25000 K, and no public calculation covers the gap (the 2025 Abel-successor models are 40–400 K planetary work).  Outside the box the table falls back to Borysow, Jørgensen & Fu 2001 — which supplies all of the wavenumber shape and the temperature dependence — rescaled by the Abel/BJF01 ratio.  That ratio is not constant: it falls almost linearly in T with a nearly wavenumber-independent slope (−0.138 dex per 1000 K, spread 0.029 over 300–9500 cm⁻¹, three-point fits good to 0.01 dex), so freezing it at the seam would bias the continuation high, and the measured trend is continued instead and frozen at 5000 K, two seam-steps out, beyond which n(H₂)² is negligible.  This matters more than it sounds: 13 of the 63 layers of the 2700 K test structure are hotter than 3000 K, beginning at τ₅₀₀₀ = 0.48. NET EFFECT at 2700 K on the PHOENIX structure: the data change (weaker Abel) and the stimulated-emission fix (stronger CIA) very nearly cancel, K 1.0378 → 1.0395 and H 1.0743 → 1.0754 vs PHOENIX; the total CIA opacity itself is −7.2% on the K continuum, of which H₂–H₂ is −5.9%, H₂–He −1.2%, and the two new pairs −0.17%. - A SECOND stimulated-emission double count removed, this time in H₂⁻ free-free (`H2MINOP`), found during a continuum-budget audit of the residual 2700 K disagreement with PHOENIX.  The CIA entry above had explicitly exempted H₂⁻, on the grounds that Turbospectrum's `detabs.f` divides its H⁻ ff table by the global (1−e^{−hν/kT}) but leaves `fakt(22)` alone.  That inferred the convention from another code's *treatment* of the table instead of from the table itself, and it was wrong.  Applying the same low-frequency test that settled the CIA case — by Kirchhoff the true, stimulated-emission-corrected free-free coefficient is j_ν/B_ν, and since j_ν → const while B_ν → 2ν²kT/c², any correctly normalised ff table must go as ν⁻², i.e. k ∝ λ², where an uncorrected one would go as λ³ — John's real tabulated points (excluding Plez's own λ² extension at 210 µm, which would beg the question) give **p = 2.00 at all seven temperatures**, in a regime as deep as hν/kT = 0.05.  The Bell & Berrington (1987) H⁻ ff table gives the identical p = 2.00, and `HMINOP` has always treated that one as already corrected.  Two tables with the same asymptote cannot carry opposite conventions, so the STIM factor in `H2MINOP` was a double count worth 1/(1−e^{−hν/kT}) — 17% of H₂⁻ at 2.2 µm / 3400 K and 8% at 1.6 µm.  Turbospectrum appears to double count it for the same reason.  WHY IT MATTERS HERE: a per-source continuum decomposition (new `DUMP_CONTINUUM` developer flag writing `<model>.cont`, read by `tools/cont_audit.py`) shows that at 2700 K the H and K continua are carried by **H₂⁻ ff, not H⁻** — at the τ_cont = 1 layer the budget is H⁻ 30.3% / H₂⁻ 51.5% / CIA 12.0% / He⁻ 5.1% in the H window and 22.8 / 42.1 / 30.8 / 4.3 in K, against H⁻ ≈ 98% in the optical.  Removing the double count therefore raises the continuum opacity by +4.5% (H) and +7.1% (K) while leaving the optical, I and J windows untouched to ≤0.2% — the same wavelength signature as the residual it was found chasing.  Ruled out along the way, by measurement rather than assertion: the 2500–5000 K gap in John's temperature grid, which straddles the actual forming layers at 3379–3454 K, costs only 1.3% in k (≈0.6% in opacity); n(H₂) agrees between the opacity routines and NMOLEC to 0.5% there (both go through `EQUILH2`, which NMOLEC also uses for its own H₂ row, so the two cannot split as TiO once did); the CIA continuation above Abel's 3000 K box covers 21% of the H/K-forming layers but a deliberate factor-of-two costs 0.71%; and no continuum source is negative anywhere in 350–2500 nm.  Two provenance weaknesses stand recorded, neither yet acted on: John (1975) is a 10 λ × 7 T table and Bell (1980, J.Phys.B 13, 1859) is a later two-centre close-coupling calculation with exchange and polarisation describing itself as in only "fair agreement" with its predecessors — at a 42–52% opacity share that difference is the right size to matter; and `HEMIOP`'s He⁻ free-free (4–5% of the H/K continuum) is a bare polynomial inherited from the F77 with no citation at all, though its own low-frequency limit does go as ν⁻², so its stimulated-emission convention at least is right.  Korg carries no H₂⁻ term at all (its H continuum is H I bf, H⁻ bf/ff, H₂⁺ bf+ff), which is defensible for the FGK regime it targets and simply not applicable at 2700 K

- MOLECULAR VAN DER WAALS BROADENING replaced with per-species data, retiring the last piece of pure guesswork in the molecular opacity.  Every molecular line in both codes previously took its vdW width from one of two hardcoded constants, selected by whether the upper-state label starts with `'X'` (1e-8) or not (1e-7), with H₂O taking a flat 1e-7 in `read_h2o`.  No molecular data entered anywhere.  Measured against ExoMol `.broad` files the 1e-7 branch — which catches every electronic band, i.e. TiO γ/γ′, CaH A–X and B–X, and all 44.6M H₂O pseudo-lines — is **10–50× too large**; the 1e-8 branch is roughly right for the heavy hydrides.  The switch encodes an *atomic* intuition (excited upper level ⇒ larger orbital ⇒ larger C₆) that does not transfer to molecules, where the whole molecule's collision cross-section sets the width, and ExoMol publishes one value per species regardless of band.  CONSEQUENCE: Voigt damping parameters of 27–44 at M-dwarf photospheric conditions where ~0.3–1 is physical, i.e. every molecular line smeared ~100× beyond its true width.  Because `voigt_profile(0,a) ≈ 1/(a√π)` for large a, that suppressed line PEAKS by ~100×, so a vast population of weak lines fell below `LINE_CUTOFF × continuum` at their first grid point, hit the wing loop's `EXIT`, and contributed nothing at all — silently deleting the weak-line haze between the H₂O bands and inside the TiO/CaH bands.  New `data/mol_broad.dat` (20 species: γ_H2, n_H2, γ_He, n_He, record count, provenance) built by `tools/build_mol_broad.py` from ExoMol `.broad`, handling all three parameterisations (`a0` keyed on J″, `a1` on J′/J″, `m0` on |m| — AlH uses `m0`).  `load_mol_broad` in `mod_mklinelist` converts each species into the code's γ_w convention — γ_w = γ(296/T)^n (kT/1e6) 2πc / (0.85 (T/1e4)^0.3) at a 3000 K reference — and fills an array indexed directly by molecule code for O(1) lookup, since it is consulted once per line across ~2.5×10⁸ lines.  Wired into all six readers; the old constants remain the fallback for species absent from the file.  EFFECT on GJ644C (2700 K, synthesis-only, unchanged production `LINE_CUTOFF = 1e-3`): TiO γ 0.547 → **0.913**, CaH 0.659 → **0.872**, optical median 0.940 → 1.067, H 1.208 → 1.097, K 1.074 → 1.000, integrated flux 1.030 → **1.009** against the Mann spectrum — i.e. the long-standing 25–45% optical molecular-band deficit largely closes, and the ATLAS12/SYNTHE and PHOENIX NewEra spectra agree to a few percent everywhere, which had not previously been true at any wavelength in the optical.  It also costs nothing: 11m18s against 12m46s, narrower lines being slightly cheaper.  COROLLARY: `LINE_CUTOFF` sensitivity collapses from 2–3% to 0.7–1.0% across 1e-3 → 1e-5 once the widths are physical (ladder: integral 1.009 / 1.003 / 1.001), so the cutoff was a symptom rather than a cause and 1e-3 remains production.  LIMITATIONS, all recorded in the data file's `src` column and the loader header: six species (CH, OH, FeH, CN, C₂, H₂) have no ExoMol file and use a named chemical analogue; 11 of the 14 with own data carry ExoMol's default n = 0.500 rather than a fitted exponent; only H₂O, CO and AlH are J/m-resolved and all three are collapsed to a median (H₂O necessarily, since its pseudo-lines came from super-line histograms that discarded J — its real spread is 4.4× across J″); the 3000 K reference bakes in a (T/3000)^(1-n-0.3) residual because the kernel hardwires a single T^0.3 scaling; and only the H₂ column is used, which makes the H₂ term exact but forces He and H I onto the hardwired atomic weights — an implied γ_He/γ_H2 = 0.494 against measured 0.53–0.56 (and 0.227 for H₂O, where it is 2.2× too high), and an implied γ_H/γ_H2 = 1.18 for which no molecular data exists at all.  That last one is not negligible with depth: on the 2700 K structure the H I share of the weighted sum runs 0.4% at 1819 K to 17.2% where H and K form and 30.2% at the bottom, as hydrogen dissociates.  Doing better means splitting `txnxn` in the opacity kernel with per-species H₂/He/H coefficients, which is more than a reader change.  Every number above is a synthesis on a structure converged with the OLD widths — the cool-star structures need reconverging before these are quoted as final
